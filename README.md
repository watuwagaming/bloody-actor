# Bloody Actor — Portfolio Site

Bloody Actor's portfolio site — a tactical, single-page site positioning the brand as a
**content creator specialist** for gaming and tech brands.

The deployed site is **fully static** (HTML + one CSS file + a little vanilla JS).
There is one optional build step — generating the CSS — covered below.

## Update workflow

The VPS has the repo cloned at `/var/www/bloody-actor`. To push a change live:

1. Edit `index.html` locally and commit + push to GitHub.
2. On the VPS (`ssh root@206.189.105.68`):
   ```bash
   cd /var/www/bloody-actor && git pull
   ```

That's it — nginx serves the files directly, no restart needed.

## Rebuilding the CSS

`assets/style.css` is generated by Tailwind from the classes used in `index.html`.
It replaces the old runtime Tailwind CDN (faster load, no flash of unstyled content).

**You only need to rebuild if new Tailwind utility classes were added to the HTML.**

1. Download the Tailwind standalone CLI (no Node needed) if you don't have it —
   `tailwindcss-windows-x64.exe` from https://github.com/tailwindlabs/tailwindcss/releases
   (use a v3.4.x release). Save it in this folder as `tailwindcss.exe`.
2. Run:
   ```
   .\tailwindcss.exe -c tailwind.config.js -i tailwind.input.css -o assets/style.css --minify
   ```
3. Commit the updated `assets/style.css` along with your HTML change.

The `.exe` is git-ignored (it's large and re-downloadable).
